# About Me photo

The About section uses one static photograph: `picture-1.jpg`. Replace this file to update the About image. The supplied file is copied byte-for-byte, displayed in its original 3:4 aspect ratio, and receives no CSS filter. The hosted project uses a Webdev storage copy; direct local `index.html` use falls back to this file. The About section currently has no carousel, second/third photo slots, or duplicate images.
