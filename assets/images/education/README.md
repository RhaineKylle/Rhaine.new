# Education logos

The current local logo assets are:

- `apolinario-mabini-logo.jpg` — Apolinario Mabini Elementary School.
- `baguio-city-high-school-logo.png` — the image supplied for Baguio City High School, used for both junior and senior high school.
- `university-of-cordilleras-logo.png` — University of the Cordilleras.

School names and local paths are editable in the `schools` array in `script.js`. The live site first uses the corresponding `/manus-storage/` asset and falls back to the local image. If an image cannot be loaded, the school initials are shown instead. Source details for downloaded logos are in `SOURCES.md`.
